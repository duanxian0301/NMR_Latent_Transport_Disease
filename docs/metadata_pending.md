# Metadata pending author approval

The following fields must be completed before a versioned release or Zenodo deposit:

- full author names and order;
- ORCID identifiers where available;
- affiliations;
- corresponding author;
- preferred citation year and release version;
- funding references and grant numbers, if included in repository metadata;
- related manuscript DOI or stable preprint identifier when available.

No `CITATION.cff` or `.zenodo.json` is included until these fields are verified.

Repository licensing has been approved: source code uses MIT, while original documentation, metadata, figure source tables and derived summary tables use CC BY 4.0. Third-party source datasets remain under their original terms and are not redistributed.
