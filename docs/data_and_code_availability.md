# Data and code availability

## Data Availability

The original metabolite GWAS summary statistics analysed in this study are available from the public sources identified by the GWAS Catalog accessions in `metadata/trait_crosswalk_61.tsv` and `metadata/input_manifest.tsv`. The repository provides the final normalized UK Biobank loading matrix, compact cross-resource and local-genetic summary tables, and source data underlying Figures 2–4. Bulk metabolite and factor GWAS files, individual-level UK Biobank data, third-party LD reference panels and local serialized caches are not redistributed. Readers must obtain those resources from the original providers and comply with their access and reuse conditions.

## Code Availability

Sanitized analysis scripts and figure-generation code are provided in this repository. The analytical scripts preserve the frozen seeds, thresholds and factor-selection rules and use environment variables in place of machine-specific paths. Source code is licensed under MIT; original documentation, metadata, figure source tables and derived summary tables are licensed under CC BY 4.0. A versioned DOI will be added only after author metadata and Zenodo integration have been verified.
