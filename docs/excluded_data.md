# Excluded data and materials

This repository intentionally excludes the following material:

- individual-level or participant-identifiable data;
- UK Biobank controlled-access resources;
- bulk harmonized or munged GWAS summary-statistic files;
- LD reference panels, PLINK reference files and LAVA correlation files;
- serialized working objects, caches, logs and temporary downloads;
- manuscript drafts, submission documents and journal PDFs;
- exploratory neurodegenerative-disease, ageing and MVMR feasibility work that was not part of the manuscript-positive result chain;
- internal prompts, bot notes and machine-specific paths.

The 61-trait public accessions and source links are provided in `metadata/input_manifest.tsv`. Readers should obtain source GWAS files from the original repositories and comply with the relevant repository terms. The included derived tables are compact, aggregate research outputs and do not replace the original GWAS resources.
