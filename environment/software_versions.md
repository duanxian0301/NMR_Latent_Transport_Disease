# Software versions

The frozen analysis used:

- R 4.4.0;
- GFA 1.0.0.0470;
- data.table 1.18.2.1;
- qs 0.27.3;
- Matrix 1.7-4;
- PLINK 1.9;
- LDSC 1.0.1;
- LAVA 0.1.5;
- Python 3.12 for parsing, structural comparison and figures.

The final figure environment used NumPy 2.5.5, pandas 3.1.1 and Matplotlib 3.11.2. The independent structural-comparison code additionally requires SciPy; the release environment pins SciPy 1.18.1.

External reference files are not redistributed. Their required roles and configuration variables are documented in `config/config.example.yaml`.
